# Mini Money — скарбничка для дітей 🎀💜

Застосунок для iPad (PWA): дитина виконує справи по дому → батьки підтверджують → монетки падають у три скарбнички → дитина збирає на свою мрію (фото іграшки + ціна).

- **Дитячий екран:** великі картки зі справами, голосова підказка українською, три скарбнички («Витратити / Накопичити / Подарувати»), головна мрія з прогресом, тиждень зі зірочками, серії 🔥, святкування з конфеті.
- **Батьківський режим:** на iPad — утримати 🔒 і ввести PIN; на телефоні батьків — одразу. Підтвердження справ і покупок, завдання (з бібліотеки за віком або свої), ціни, бонуси, перекладання між скарбничками, історія.
- **Гроші:** монетки (курс, напр. 1 монетка = 5 грн) або гривні. Ціни зберігаються в копійках, тож перемикання нічого не ламає.
- **Теми:** «Кітті й Куромі», «Космос», «Лісові друзі».
- **Офлайн:** працює без інтернету, синхронізується, коли мережа з'явиться.

## Встановлення на iPad
1. Відкрити сайт у **Safari** (напр. `https://yegoriy90.github.io/mini_money/`).
2. Кнопка «Поділитися» → **«На початковий екран»**.
3. Запускати з іконки «Скарбничка»: на весь екран, як звичайний застосунок.

> На iOS застосунок з іконки має окреме сховище від Safari, тож налаштовувати треба вже в ньому.

Порада: «Параметри → Універсальний доступ → Гід-доступ» прив'яже iPad до одного застосунку.

## Синхронізація (Firebase), ~10 хвилин, безкоштовно
Без цього все працює на одному iPad. Щоб підтверджувати справи з телефона:

1. https://console.firebase.google.com → **Add project** → назва `mini-money` → Google Analytics вимкнути.
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable**.
3. **Build → Firestore Database → Create database** → регіон `eur3 (europe-west)` → *production mode*.
   Вкладка **Rules** → вставити вміст `firestore.rules` → **Publish**.
4. ⚙️ **Project settings → General → Your apps → `</>` (Web)** → назва `mini-money` → скопіювати об'єкт `firebaseConfig`.
5. Вставити його в `js/firebase-config.js` замість `null` (або передати Claude):
   ```js
   export const firebaseConfig = { apiKey: '…', authDomain: '…', projectId: '…', storageBucket: '…', messagingSenderId: '…', appId: '…' };
   ```
6. **Authentication → Settings → Authorized domains** → додати `yegoriy90.github.io`.

Потім у батьківському режимі на iPad: **Налаштування → Синхронізація → «Увімкнути синхронізацію»**: дані перенесуться в хмару, з'явиться **код сім'ї**. На телефоні відкрити сайт → «У мене є код сім'ї» → ввести код → «Телефон батьків».

Ключі Firebase не секретні: доступ захищають правила (тільки за 10-символьним кодом сім'ї, список сімей отримати не можна).

## Розробка
Без збірки: чистий HTML/CSS/JS-модулі.
```sh
python3 -m http.server 8765            # http://localhost:8765
node tools/make_icons.js               # PNG-іконки з icons/icon.svg
# локальний Firebase: firebaseConfig = { apiKey: 'demo', projectId: 'demo-mini-money', appId: '1:1:web:1', emulator: 'localhost' }
npx firebase-tools emulators:start --only auth,firestore --project demo-mini-money
```
