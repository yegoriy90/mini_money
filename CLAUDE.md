# Mini Money — дитяча скарбничка (PWA для iPad)

Відповідай українською, неформально. Для Мії (5 років) — пізніше інші вікові групи.

## Структура
- `index.html` — оболонка; `?v=` у підключеннях `css/app.css` і `js/app.js` + `VERSION` у `sw.js` піднімати при кожній зміні.
- `js/app.js` — UI: онбординг, дитячий екран (справи / мрії / успіхи), батьківський режим (PIN), вікна, дії (`A`), форми.
- `js/model.js` — логіка: гроші в **копійках**, баланс = сума `ledger`; `splitReward` (розподіл по скарбничках за «недобором», без зменшень), серії, `approveOps`/`buyOps`.
- `js/store.js` — `LocalStore` (localStorage, fid `local`) і `CloudStore` (Firestore `families/{fid}/{meta|tasks|wishes|completions|ledger}`), однаковий API `watch/batch`. `migrateToCloud`.
- `js/library.js` — набори завдань за віком (ціни в монетках; гігієна = 0, лише серія). Курс за замовчуванням 1 монетка = 10 грн, скарбнички 50/40/10, доплата батьків 50% до «Накопичити» (`matchEntry`, лише після `matchSince`). Машини в сім'ї немає — завдань з авто не додавати. `js/themes.js` — теми й SVG-персонажі (спрощені, власні). `js/fx.js` — голос (uk-UA), звуки WebAudio, конфеті.
- `js/firebase-config.js` — `null` = локальний режим. `firestore.rules`, `firebase.json` (емулятор).
- `sw.js` — офлайн, мережа першою.
- Щоденні звички (`repeat: daily`) дають ❤️ замість монеток: `heartsPerCoin` (5) сердечок → 1 монетка (запис `hearts_<heartsSince>_<n>`, ділиться по скарбничках, з доплатою). Рахуються підтвердження після `heartsSince` (для старих профілів ставиться при першому завантаженні). На дитячому екрані — окремі блоки «Щоденні звички» і «Справи за монетки».
- Бонус серії — сердечками (запис `heartbonus` з полем `hearts`, amounts порожні). Звички мають `time`: morning/evening/'' (вкладки 🌅/🌙/☀️ на дитячому екрані).
- 💵 Видати готівкою — запис `cash` (Гроші). Наліпки: 1 за кожні 10 підтверджених справ (`STICKERS` у library.js). Мрія-пазл 3×3. Вкладка батьків «📊 Тиждень». Нагадування про копію, якщо >7 днів.
- Голос персонажа: `say(keys, text)` у fx.js грає `audio/voice/<key>.mp3` зі списку `audio/voice/index.js`, інакше — синтезатор. Файли з Magnific (CDN `pikaso.cdnpk.net` має бути дозволений у мережі середовища).
- У тестах Playwright підміняти `js/firebase-config.js` на `null` (локальний режим) або емулятор.
- Дитина сама перекладає монетки (`kidMove`): тап по скарбничці → вікно, по 1 монетці, один запис `move` при закритті.
- Перенос без Firebase: Налаштування → «📤 Зберегти копію» (JSON з усіма колекціями) → на іншому пристрої «📥 Відкрити з файлу» (онбординг або налаштування), стає локальним `fid: local`, роль child.

## Правила
- Репозиторій **публічний**: жодних імен, фото чи кодів сім'ї в коді. Дані — лише в localStorage/Firestore.
- Ідемпотентні id записів: `earn_<completionId>`, `bonus_<id>`, `match_<id>`, `buy_<wishId>`, щоденна справа `<taskId>_<YYYY-MM-DD>`.
- Перевірка: Playwright 1180×820 (iPad), 820×1180, 390 (телефон); без помилок у консолі, без горизонтального скролу. Хмару — на емуляторі (Firebase SDK з npm `firebase@10.12.2`, підміна gstatic через `ctx.route`).
