# Mini Money — дитяча скарбничка (PWA для iPad)

Відповідай українською, неформально. Для Мії (5 років) — пізніше інші вікові групи.

## Структура
- `index.html` — оболонка; при кожній зміні піднімати разом: `?v=` у `index.html`, `window.MM_VERSION` там же, `VERSION` і `?v=` у списку `SHELL` у `sw.js` (нові js-файли — теж у `SHELL`).
- `js/app.js` — UI: онбординг, дитячий екран (справи / мрії / успіхи), батьківський режим (PIN), вікна, дії (`A`), форми.
- `js/model.js` — логіка: гроші в **копійках**, баланс = сума `ledger`; `splitReward` (розподіл по скарбничках за «недобором», без зменшень), серії, `approveOps`/`buyOps`.
- `js/store.js` — `LocalStore` (localStorage, fid `local`) і `CloudStore` (Firestore `families/{fid}/{meta|tasks|wishes|completions|ledger}`), однаковий API `watch/batch`. `migrateToCloud`.
- `js/library.js` — набори завдань за віком (ціни в монетках; гігієна = 0, лише серія). Курс за замовчуванням 1 монетка = 10 грн, скарбнички 50/40/10, доплата батьків 50% до «Накопичити» (`matchEntry`, лише після `matchSince`). Машини в сім'ї немає — завдань з авто не додавати. `js/themes.js` — теми й SVG-персонажі (спрощені, власні). `js/fx.js` — голос (uk-UA), звуки WebAudio, конфеті.
- `js/firebase-config.js` — `null` = локальний режим. `firestore.rules`, `firebase.json` (емулятор).
- Доступ до хмари — **членство** (з v19): `families/{fid}/members/{uid}` `{role, label, joinedAt, invite?}`; дані читають лише записані пристрої. Новий пристрій — одноразовий код `invites/{8 символів}` (30 хв). Корінь сім'ї `{createdAt, owner, legacy}`: поки `legacy` не `false`, старий 10-символьний код ще пускає (пристрій сам записується в `connect()` → `ensureMember`); «🔒 Закрити старий код» ставить `legacy:false`. Налаштування → Синхронізація: список пристроїв, «Відключити», «➕ Додати пристрій»; «🗑 Видалити сім'ю й усі дані». Відключення/видалення ловиться наживо (слухач members). Тести: `scratchpad/members.js`, `transition.js` (старі → нові правила) на емуляторі; дані емулятора через REST з `Authorization: Bearer owner`.
- `sw.js` — офлайн, мережа першою.
- Щоденні звички (`repeat: daily`) дають ❤️ замість монеток: `heartsPerCoin` (5) сердечок → 1 монетка (запис `hearts_<heartsSince>_<n>`, ділиться по скарбничках, з доплатою). Рахуються підтвердження після `heartsSince` (для старих профілів ставиться при першому завантаженні). На дитячому екрані — окремі блоки «Щоденні звички» і «Справи за монетки».
- Бонус серії — сердечками (запис `heartbonus` з полем `hearts`, amounts порожні). Звички мають `time`: morning/evening/both/'' (вкладки 🌅/🌙/☀️ на дитячому екрані). `both` — двічі на день (зубки): дві картки, completion з полем `slot` і id `<taskId>_<дата>_<slot>`; бонус серії — лише за перше підтвердження дня.
- 💵 Видати готівкою — запис `cash` (Гроші). Наліпки: 1 за кожні 10 підтверджених справ — 36 згенерованих картинок `assets/stickers/NN.webp` (Magnific, 4 аркуші 3×3 на зеленому фоні → `tools/cut_stickers.py`), порядок і назви в `STICKERS` (library.js); закриті показуються силуетами. Мрія-пазл 3×3. Вкладка батьків «📊 Тиждень» (підсумки, по днях, топ-5 і «Усі справи по днях» — хронологія з часом, нагородою і статусом ✅/⏳/✕). Нагадування про копію, якщо >7 днів.
- Голос персонажа: `say(keys, text)` у fx.js грає `audio/voice/<key>.mp3` зі списку `audio/voice/index.js`, інакше — синтезатор. Голос Lila (ElevenLabs v3, voiceId 513), 46 **загальних** фраз (без назв справ, сум і імен), лише жіночі форми (`sayF`; для хлопчика — синтезатор з тим самим загальним текстом). Синтезатор для дівчинки не використовується: відсутній кліп просто пропускається. Нові фрази — тільки загальні. Карта ключ→creation у `tools/voice_map.json`; нові/перезаписані кліпи: свіжі URL з `creations_get` → `node tools/fetch_voice.js urls.json` (curl; потім ffmpeg моно 64k). Один спільний `Audio`-плеєр, розблокований першим дотиком (iOS). Відео святкування — див. розділ App Store.
- У тестах Playwright підміняти `js/firebase-config.js` на `null` (локальний режим) або емулятор.
- Справи на дитячому екрані — каруселі (`.carousel` > `.car-track`, scroll-snap, стрілки ‹ ›), прокрутка зберігається між render().
- Дитина сама перекладає монетки (`kidMove`): тап по скарбничці → вікно, по 1 монетці, один запис `move` при закритті.
- Перенос без Firebase: Налаштування → «📤 Зберегти копію» (JSON з усіма колекціями) → на іншому пристрої «📥 Відкрити з файлу» (онбординг або налаштування), стає локальним `fid: local`, роль child.

## Правила
- Деплой: GitHub Pages з `main`. Зміни — через PR з гілки сесії; **дрібні PR Claude мерджить сам після тестів** (дозвіл власника, 25.10.2026). Великі/ризикові (схема даних, Firestore rules, видалення) — спершу питати.
- Репозиторій **публічний**: жодних імен, фото чи кодів сім'ї в коді. Дані — лише в localStorage/Firestore.
- Ідемпотентні id записів: `earn_<completionId>`, `bonus_<id>`, `match_<id>`, `buy_<wishId>`, щоденна справа `<taskId>_<YYYY-MM-DD>`.
- Перевірка: Playwright 1180×820 (iPad), 820×1180, 390 (телефон); без помилок у консолі, без горизонтального скролу. Хмару — на емуляторі (Firebase SDK з npm `firebase@10.12.2`, підміна gstatic через `ctx.route`).

## App Store (у роботі з 15.11.2026)
- **Компаньйони (з v24):** дитина обирає друга (онбординг, тап по героєві в шапці, налаштування) — `COMPANIONS` у themes.js, поле `settings.theme` = id компаньйона (старі `toys/kitty/space/forest` мапляться в `themeId`). Колір теми — від компаньйона (`applyColors` → `--tab/--tab-2/--tab-deep`). 12 героїв: Флопі, Мусі + 10 оригінальних плюшевих (Magnific, фон прибрано, `tools/cut_heroes.py` → `assets/heroes/<img>.webp`; круглі аватари з усією головою — `tools/make_avatars.py` → `<img>-avatar.webp`, межа голови (частка висоти): flopi .30, monkey .30, leo .40, dino .36, pingo .38, bublik .36, rusia .42, zirka .42, mur .40, bambu .42, khvylia .42, iskra .42). Нових героїв не копіювати з чужих ігор/брендів. Оформлення — `css/candy.css` поверх app.css, у дусі iOS (з v28): світлий фон з відтінком друга, білі картки (радіуси 22/16/12, ледь помітна тінь), колір друга лише як акцент, типографіка iOS (34/22/17/13, жирність 700/600), segmented control, tab bar. Не повертати насичені градієнти, скло на картках, тіні під текстом — власник вважає це «колхозом».
- **Друзі за віком (з v30):** `COMPANIONS` має поле `age` ('4-5' плюшеві / '6-7' мультяшні мандрівники / '8-10' герої-підлітки в стилі ігрових персонажів), по 12 на вік. Вибір друга — вкладки за віком; коли батьки підняли вік, а друг «молодший», дитині один раз показується «Ти підросла!» (`settings.friendAgeSeen`). Дитина може перейменувати друга — `settings.friendNames {id: ім'я}`, показ через `friendName(c, s)`. Межі голови для аватарів нових героїв: 6–7 ≈ .45–.55, 8–10 ≈ .17–.25 (бриз — без дошки, вирізати перед make_avatars).
- Мета — публічний застосунок. Герої — **Флопі** (сірий вухастий зайчик, менший) і **Мусі** (веселкова мавпочка) — за справжніми іграшками Мії. Ім’я — `HEROES` у themes.js. Тема `toys` (стара `kitty` мапиться на неї через `themeId`). Картинки `assets/heroes/` (повний зріст + голівки, вирізані з Magnific-генерації; `pair-square.jpg` — кадр для відео). Відео святкування `assets/cele-heroes.mp4` (MiniMax H3 Turbo, старт=кінець). Іконка `icons/icon-1024.png` → також `ios/.../AppIcon-512@2x.png`. Hello Kitty / Kuromi з коду прибрані.
- Нативна обгортка: Capacitor 8 (`capacitor.config.json`, appId `ua.minimoney.app`, папка `ios/`, SPM). `npm run build:www` збирає `www/` (Firebase SDK локально в `www/vendor/firebase`, бо в нативі `location.protocol === 'capacitor:'`), `npm run ios:sync` → Xcode на Mac.
- `privacy.html` і `support.html` (uk + en, стиль `css/page.css`) — для App Store: https://yegoriy90.github.io/mini_money/privacy.html, …/support.html. Посилання — внизу батьківських налаштувань (за PIN = батьківський бар'єр; у нативі — повна адреса, `SITE` в app.js). Контакт поки — GitHub Issues (публічні), краще окрема пошта. При зміні збору даних — оновлювати політику й дату.
- Шрифт Nunito локально (`css/fonts.css`, `assets/fonts/`, OFL) — жодних запитів до Google Fonts (дитяча категорія: без сторонніх запитів, крім Firebase при синхронізації).
- Нативне (`js/native.js`, у браузері — нічого не робить): haptics на звуках (`sound.*` у fx.js), нагадування про звички — локальні сповіщення, налаштування лише пристрою (`mm.remind` у localStorage, «Цей пристрій» у налаштуваннях), фото мрії — плагін Camera (у `Info.plist` описи дозволів камери/фото). Тестова збірка в локальному режимі: після `build:www` замінити `www/js/firebase-config.js` на `null` + `npx cap copy ios`.
- Ще треба: Sign in with Apple (не обов'язково — немає стороннього входу); скриншоти й опис; перевірити комерційну ліцензію Magnific на голос/картинки.
